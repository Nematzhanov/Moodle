## Intent

Промо сайта CodeCheck — детектора ИИ-кода на C++ для преподавателей. Продать, а не показать сайт как есть.
Сюжет: вопрос с первого экрана «Код написал студент или нейросеть?» → код в редакторе → сканирование →
наезд камеры на подозрительные строки → 91% ИИ → цифры качества (96,3% точность, 5,4% ложных срабатываний) →
CTA «Проверьте код». Пользователь: «чтобы камера прям плавно наезжала, выезжала, отличный motion-дизайн».

## Notes

- Референсы: тёмный UI, плавные наезды/отъезды камеры на детали интерфейса, курсор, короткие заголовки, мягкие переходы.
- Цифры только реальные: 96,3% точность (214 примеров), 5,4% ложных (6 из 111). 91% — демо-пример с сайта.
